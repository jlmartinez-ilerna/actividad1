# 📚 Actividad 2 – Control de Versiones con Git y GitHub

Repositorio de prácticas del módulo **Despliegue de Aplicaciones Web** (2º DAW – Campus FP Córdoba).

## 🎯 Propósito del proyecto

Este repositorio sirve para practicar el **control de versiones** con Git y GitHub:

1. Crear archivos y subirlos al repositorio remoto (`add`, `commit`, `push`).
2. Publicar una **Release** desde la interfaz web de GitHub.
3. Guardar trabajo temporal con `git stash`.
4. Documentar el proyecto con **Markdown**.
5. Excluir archivos innecesarios con `.gitignore`.
6. Trabajar con **ramas** y fusionarlas con `git merge`.
